## Dois tipos de ferramentas

O Decopilot tem acesso a dois tipos de ferramentas:

**Ferramentas built-in** — sempre disponíveis, usadas para gerenciar trabalho, delegar tarefas e ler contexto. As mesmas independentemente do escopo.

**Ferramentas de escopo** — vêm das conexões anexadas no seu escopo atual. No escopo de organização, são as built-ins de toda a organização. No escopo de agente, são as ferramentas anexadas ao agente aberto.

---

## Ferramentas built-in

| Ferramenta | Disponível em subtarefas | O que faz |
|---|:---:|---|
| `subtask` | Não | Inicia uma subtarefa, opcionalmente com um agente específico |
| `user_ask` | Não | Pergunta a você quando precisa de input |
| `enable_tool` | Sim | Ativa uma ferramenta de escopo para que ela possa ser chamada no próximo passo |
| `read_resource` | Sim | Lê documentação ou diretrizes do escopo atual |
| `read_prompt` | Sim | Lê um template de prompt reutilizável |
| `read_tool_output` | Sim | Relê um resultado grande de ferramenta que foi descarregado para armazenamento |
| `web_search` | Sim | Executa uma pesquisa web profunda e transmite o resultado (requer um modelo de pesquisa web) |
| `generate_image` | Sim | Gera uma imagem com o modelo de imagem configurado |
| `propose_plan` | Não | Propõe um plano para aprovação (registrada apenas no modo plan) |

Subtarefas têm acesso restrito — não podem iniciar subtarefas adicionais nem fazer perguntas a você, já que são feitas para executar e reportar de volta sem interrupção.

### Agentes apoiados por sandbox recebem VM tools

Quando um agente tem um sandbox (um repositório do GitHub vinculado, veja [Agents](/pt-br/studio/agents)), o Decopilot também recebe seis **VM tools** que operam dentro desse sandbox:

| Ferramenta | O que faz |
|---|---|
| `bash` | Executa um comando de shell no sandbox |
| `read` | Lê um arquivo do sandbox |
| `write` | Escreve um arquivo no sandbox |
| `edit` | Aplica uma edição direcionada a um arquivo existente |
| `grep` | Pesquisa conteúdo de arquivos com ripgrep |
| `glob` | Lista arquivos que correspondem a um padrão de caminho |

Essas ferramentas são provisionadas de forma preguiçosa — o sandbox só inicia na primeira chamada de VM tool.

## Ferramentas de escopo

Ferramentas de escopo são as capacidades específicas de domínio atreladas ao seu contexto atual. Abra um agente e você verá as ferramentas anexadas a ele — ferramentas Shopify se o agente tiver a conexão Shopify, ferramentas de envio se tiver ShipStation, e assim por diante.

**Exemplo**: um agente de fulfillment de pedidos pode expor:

- `GET_ORDERS` — busca pedidos de clientes
- `UPDATE_INVENTORY` — atualiza níveis de estoque
- `CREATE_SHIPPING_LABEL` — gera etiquetas de envio
- `GET_PRODUCTS` — lista o catálogo de produtos

Quais ferramentas estão disponíveis depende das conexões anexadas ao agente atual. Veja [Agents](/pt-br/studio/agents) para saber como organizar isso.

---

## Como o Decopilot usa ferramentas

O Decopilot começa cada tarefa apenas com suas ferramentas built-in. Ele vê as ferramentas de escopo listadas em suas instruções e as utiliza conforme necessário para completar sua solicitação.

Para trabalhos complexos, pode delegar a uma subtarefa (usando `subtask`) ou carregar contexto adicional primeiro (usando `read_resource` ou `read_prompt`) antes de agir.
