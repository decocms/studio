## Visão geral

Faz uma pergunta ao usuário para obter entrada ou esclarecimento. Suporta entrada de texto, múltipla escolha ou confirmação. O status da task muda para "Needs Input" até que o usuário responda.

## Disponibilidade

- **Tasks**: ✓ Disponível
- **Subtasks**: ✗ Não disponível (evita bloqueio)

<Callout type="warning">
  **Restrição**: Esta ferramenta está disponível apenas em tasks, não em subtasks. Subtasks executam de forma autônoma sem bloquear esperando entrada do usuário.
</Callout>

## Assinatura

```typescript
user_ask(
  question: string,
  options?: UserAskOptions
)

type UserAskOptions = {
  type?: "text" | "choice" | "confirm"
  choices?: string[]
  default?: string | boolean
}
```

## Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
|-----------|------|----------|-------------|
| `question` | `string` | Obrigatório | A pergunta a ser feita ao usuário |
| `options` | `UserAskOptions` | Opcional | Opções para a pergunta |
| `options.type` | `"text" \| "choice" \| "confirm"` | Opcional | Tipo de entrada esperada (padrão: "text") |
| `options.choices` | `string[]` | Opcional | Opções disponíveis (obrigatório para `type: "choice"`) |
| `options.default` | `string \| boolean` | Opcional | Valor padrão |

## Retorno

Resposta do usuário como string ou boolean (dependendo do tipo da pergunta).

## Comportamento

- O status da task muda para "Needs Input" até que o usuário responda
- Bloqueia a execução da task até que o usuário forneça uma resposta
- Disponível apenas em tasks (não em subtasks) para evitar bloqueio de trabalho autônomo

## Exemplo de uso

### Entrada de texto

```typescript
const apiKey = user_ask("What is your GitHub API key?")
```

### Múltipla escolha

```typescript
const environment = user_ask(
  "Which environment should I deploy to?",
  {
    type: "choice",
    choices: ["staging", "production"],
    default: "staging"
  }
)
```

### Confirmação

```typescript
const proceed = user_ask(
  "This will delete all data. Are you sure?",
  {
    type: "confirm",
    default: false
  }
)

if (proceed) {
  // Execute destructive action
}
```

### Esclarecimento durante a execução

```typescript
// Gather requirements
const features = user_ask("Which features should I enable? (comma-separated)")

// Use the input
const featureList = features.split(",").map(f => f.trim())
```

## Casos de uso

### Obter informações faltantes

```typescript
const dbUrl = user_ask("What is the database connection string?")
```

### Confirmar ações destrutivas

```typescript
const confirmed = user_ask(
  "This will overwrite existing files. Continue?",
  { type: "confirm" }
)
```

### Obter preferências do usuário

```typescript
const style = user_ask(
  "Which code style do you prefer?",
  {
    type: "choice",
    choices: ["functional", "object-oriented"],
    default: "functional"
  }
)
```
