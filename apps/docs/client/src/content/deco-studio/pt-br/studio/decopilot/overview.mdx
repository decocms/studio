## O que é o Decopilot?

O **Decopilot** é o assistente de IA integrado ao deco Studio. Ele consegue atuar em todas as suas ferramentas conectadas — Shopify, bancos de dados, e-mail, plataformas de atendimento ao cliente e muito mais — a partir de um único chat.

Você inicia uma conversa e o Decopilot trabalha em segundo plano. Quando precisa do seu input, ele pergunta. Caso contrário, segue em frente, coordenando múltiplos serviços em seu nome.

## Como funciona

O Decopilot segue um ciclo simples: entender a tarefa → executar uma ação → verificar o resultado → repetir. Ele lê dos seus serviços conectados, chama as ferramentas certas e se adapta com base no que aprende.

O que o diferencia de um chat de IA comum é que ele consegue alcançar os apps onde seu trabalho realmente acontece — não está limitado a responder perguntas. Ele pode consultar pedidos, atualizar registros, enviar notificações e coordenar workflows em múltiplos serviços de uma só vez.

## Escopo: onde você está trabalhando determina o que está disponível

O Decopilot se adapta ao lugar onde você está no Studio:

- **Escopo de organização** — você está na tela inicial sem nenhum agente aberto. O Decopilot tem acesso às ferramentas built-in de toda a organização (gerenciar conexões, agentes, membros) e ao seu catálogo completo de agentes.
- **Escopo de agente** — você abriu um agente específico. O Decopilot passa a usar as ferramentas e instruções *daquele agente*, com o histórico de threads do agente como contexto.

Para trocar, basta abrir ou fechar um agente pela barra lateral. Não há nada extra para configurar.

<Callout type="info">
  Um terceiro nível — escopo de projeto — está planejado. Ele ficará entre organização e agente e agrupará ferramentas/contexto para um time ou cliente. Veja [Projetos](/pt-br/studio/projects).
</Callout>

## Modos de chat

A entrada de chat tem um seletor de modo que define como o Decopilot aborda uma rodada. Você pode trocar de modo a qualquer momento sem perder sua conversa.

| Modo | O que muda |
|---|---|
| **Padrão** | Chat normal — o Decopilot escolhe as ferramentas por conta própria. |
| **Plan** | O Decopilot deve encerrar a rodada com uma chamada `propose_plan`. Ferramentas destrutivas são bloqueadas até você aprovar um plano; apenas ferramentas somente leitura podem ser habilitadas. Útil antes de fazer algo arriscado. |
| **Web search** | O primeiro passo é forçado a chamar `web_search`, que transmite uma pesquisa profunda diretamente para você. Requer um modelo de pesquisa web em [AI Providers](/pt-br/studio/ai-providers). |
| **Gen image** | O primeiro passo é forçado a chamar `generate_image`. Requer um modelo de imagem. |

## Modelos

O Decopilot funciona com múltiplos provedores de IA — Anthropic, Google, OpenRouter, o Deco AI Gateway e modelos self-hosted. Escolha um modelo mais robusto para tarefas complexas e um mais rápido para operações simples. Veja [AI Providers](/pt-br/studio/ai-providers).

## Agentes e subtarefas

Quando uma tarefa precisa de um trabalho focado — uma pergunta de atendimento ao cliente, uma pesquisa aprofundada, uma análise de dados — o Decopilot pode delegá-la a um [agente](/pt-br/studio/agents) especialista em uma **subtarefa**. A subtarefa roda de forma independente com seu próprio contexto limpo, e então reporta um resumo de volta. Sua conversa principal permanece limpa.

## Ferramentas built-in

O Decopilot vem com ferramentas para coordenar trabalho em qualquer escopo:

| Ferramenta | O que faz |
|---|---|
| `subtask` | Delega trabalho a um agente especialista |
| `user_ask` | Faz uma pergunta a você quando precisa de esclarecimento |
| `enable_tool` | Ativa uma ferramenta de escopo para uso nos próximos passos |
| `read_resource` | Lê documentação ou diretrizes disponíveis no escopo |
| `read_prompt` | Lê um template de prompt reutilizável |
| `read_tool_output` | Relê um resultado anterior de ferramenta que foi descarregado para armazenamento |
| `web_search` | Executa uma pesquisa web profunda e transmite o resultado |
| `generate_image` | Cria uma imagem com o modelo de imagem configurado |
| `propose_plan` | Propõe um plano para sua aprovação (somente no modo plan) |

Quando um agente é apoiado por um sandbox (um repositório do GitHub vinculado), o Decopilot também recebe seis **VM tools** — `bash`, `read`, `write`, `edit`, `grep`, `glob` — para que possa executar e modificar código nesse sandbox.

Para a referência completa, veja [Tools](/pt-br/studio/decopilot/tools).
