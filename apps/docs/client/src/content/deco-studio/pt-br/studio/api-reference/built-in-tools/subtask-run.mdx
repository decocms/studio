## Visão geral

Cria uma subtarefa com contexto isolado. Opcionalmente, especifique um agente para usar na subtarefa. A subtarefa executa até a conclusão e então retorna os resultados.

## Disponibilidade

- **Tasks**: ✓ Disponível
- **Subtasks**: ✗ Não disponível (evita delegação infinita)

<Callout type="warning">
  **Restrição**: Esta ferramenta está disponível apenas em tasks, não em subtasks. Isso evita cadeias infinitas de delegação e garante que subtasks sejam concluídas de forma independente.
</Callout>

## Assinatura

```typescript
subtask(prompt: string, agent_id?: string)
```

## Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
|-----------|------|----------|-------------|
| `prompt` | `string` | Obrigatório | A descrição da tarefa para a subtask |
| `agent_id` | `string` | Opcional | Agente específico a ser usado na subtask |

## Retorno

Resultados da subtask e status de conclusão.

## Comportamento

- Cria uma subtask com contexto isolado
- Se `agent_id` for omitido, a subtask usa as capacidades do escopo atual
- Se `agent_id` for especificado, a subtask usa as capacidades daquele agente
- A subtask executa até a conclusão e então retorna os resultados
- Subtasks não podem criar subtasks adicionais (evita delegação infinita)
- Subtasks não podem fazer perguntas ao usuário (evita bloqueio)

## Exemplo de uso

```typescript
// Spawn subtask with current scope
subtask("Analyze the error logs and identify the root cause")

// Spawn subtask with specific agent
subtask(
  "Review the pull request for code quality issues",
  "code-review-agent"
)

// Parallel subtasks for independent work
subtask("Deploy to staging environment")
subtask("Run integration tests")
```

## Casos de uso

### Execução paralela

Crie múltiplas subtasks para trabalhos independentes que podem ser executados em paralelo:

```typescript
subtask("Analyze inventory levels across all warehouses")
subtask("Fetch pending customer orders from Shopify")
subtask("Check shipping carrier delivery status")
```

### Execução especializada

Delegue o trabalho a um agente especialista específico passando seu id:

```typescript
subtask("Review this pull request", "agent_abc123")
```

### Contexto isolado

Crie um contexto isolado para trabalho focado sem poluir a task principal:

```typescript
subtask("Generate a detailed technical report on the performance bottlenecks")
```
