## Coloque o Studio para rodar

Existem duas formas de começar.

### Opção A — Cloud gerenciada

Cadastre-se em [studio.decocms.com](https://studio.decocms.com) e está tudo pronto.

1. Crie sua conta (email, GitHub ou Google)
2. Crie uma organização — seu workspace de nível mais alto
3. Pronto, você está dentro.

### Opção B — Rodar localmente

```bash
bunx -p decocms deco
```

Isso sobe uma instância local com PostgreSQL embutido. Totalmente privado — tudo fica na sua máquina. O pacote é publicado como `decocms`; o binário que ele entrega é `deco`. Ou clone e rode a partir do código-fonte:

```bash
git clone https://github.com/decocms/studio.git
cd studio
bun install
bun run dev
```

## AI provider (já configurado para você)

Novas organizações começam com créditos no **Deco AI Gateway**, então você pode começar a conversar com agentes imediatamente — sem nenhuma configuração.

Quando quiser usar suas próprias keys (Anthropic, Google, OpenRouter, etc.) ou verificar quanto resta do crédito do gateway, vá em **Settings → AI Providers**. Veja [AI Providers](/pt-br/studio/ai-providers) para a lista completa.

## Crie ou abra um agente

A sidebar mostra seus agentes. Clique em um existente ou crie um novo pelo botão **+**.

Quando você está dentro de um agente, a tela tem três partes:

- **Esquerda** — a lista de threads (conversas anteriores com este agente)
- **Centro / inferior** — o input do chat
- **Direita** — o painel do agente: **Settings** (instruções, connections), **Automations** e **Git** (se vinculado)

Abra a aba **Settings** à direita e escreva uma instrução de uma linha descrevendo o que este agente deve fazer.

---

## Anexe uma connection

Connections são as ferramentas que seu agente pode usar — GitHub, Slack, Shopify, seu banco de dados, seu próprio MCP server. Você pode adicioná-las diretamente a partir do agente que acabou de criar:

1. No painel direito do agente, em **Settings**, abra a seção **Connections**
2. Clique em **Add connection**
3. Pesquise no catálogo (ex.: Gmail) ou escolha **Custom Connection** para adicionar um MCP server não listado
4. Clique em **Connect** e siga o fluxo de sign-in ou cole uma key
5. Escolha quais ferramentas dessa connection este agente deve ter

As credenciais são criptografadas e nunca expostas ao seu time. Connections adicionadas dessa forma ficam armazenadas no **nível da org** — aparecem em **Settings → Connections** e podem ser anexadas a outros agentes também.

<Callout type="tip">
  Você também pode começar por **Settings → Connections** e instalar uma connection antecipadamente, e depois anexá-la aos agentes. O resultado é o mesmo — escolha a ordem que fizer mais sentido.
</Callout>

O catálogo é populado pelos registries habilitados em **Settings → Store**.

## Converse com ele

Basta digitar. O agente usa as ferramentas que você anexou.

```
Send an email to me@example.com with a poem about MCP.
```

Acompanhe a execução no chat. Cada chamada de ferramenta é registrada em **Settings → Monitor**.

<Callout type="success">
  Tudo pronto! A partir daqui, configure [Automations](/pt-br/studio/automations) para rodar agentes em uma agenda ou evento, convide [members](/pt-br/studio/user-management) do time, ou construa mais agentes.
</Callout>
