## Coloque o Studio para rodar

Existem duas formas de começar.

### Opção A — Cloud gerenciada

Cadastre-se em [studio.decocms.com](https://studio.decocms.com) e está tudo pronto.

1. Crie sua conta (email, GitHub ou Google)
2. Crie uma organização — seu workspace de nível mais alto
3. Pronto, você está dentro.

### Opção B — Rodar localmente

```bash
bunx decocms
```

Isso sobe uma instância local com PostgreSQL embutido. Totalmente privado — tudo fica na sua máquina. Ou clone e rode a partir do código-fonte:

```bash
git clone https://github.com/decocms/studio.git
cd studio
bun install
bun run dev
```

<Callout type="tip">
  **Está no Mac?** Você também pode instalar o app nativo para desktop: rode `curl -fsSL https://studio.decocms.com/install.sh | sh` no Terminal, ou abra o menu de conta na parte inferior da sidebar e clique em **Install on Mac**. Por enquanto só Apple Silicon — suporte para Windows está chegando.
</Callout>

## AI provider (já configurado para você)

Novas organizações começam com créditos no **Deco AI Gateway**, então você pode começar a conversar com agentes imediatamente — sem nenhuma configuração.

Quando quiser usar suas próprias keys (Anthropic, Google, OpenRouter, etc.) ou verificar quanto resta do crédito do gateway, vá em **Settings → AI Providers**. Veja [AI Providers](/pt-br/studio/ai-providers) para a lista completa.

## Comece a conversar (Decopilot)

Você não precisa construir nada para começar. A tela inicial é um composer de chat — _"What's on your mind?"_ — alimentado pelo **Decopilot**, o assistente embutido do Studio. Digite um pedido e ele põe mãos à obra, usando quaisquer tools que você tenha conectado. Cada conversa fica salva em **Decopilot**, na sidebar à esquerda.

Quando estiver pronto para criar um worker focado e reutilizável, crie um agent dedicado.

## Crie um agent

Use o botão **+** / "Browse agents" na sidebar para criar um novo agent. Assim que ele abrir, a tela se divide em duas partes:

- **Esquerda** — o chat. Acima do input ficam o **model picker** (nível do modelo) e o **runtime picker** (onde o agent roda — na cloud ou na sua própria máquina; veja [Agents](/pt-br/studio/agents#where-an-agent-runs)).
- **Direita** — um painel com abas. A aba **Settings** guarda instruções, connections e arquivos; **Automations** guarda schedules e triggers. Outras abas (Preview, Content, Review changes) aparecem apenas para agents vinculados a um repo ou site.

Abra a aba **Settings** e escreva uma instrução de uma linha descrevendo o que este agent deve fazer.

## Anexe uma connection

Connections são as tools que seu agent pode usar — GitHub, Slack, Shopify, seu banco de dados, seu próprio MCP server. Você pode adicioná-las diretamente a partir do agent que acabou de criar:

1. No painel direito do agent, em **Settings**, abra a seção **Connections**
2. Clique em **Add connection**
3. Pesquise no catálogo (ex.: Gmail) ou escolha **Custom Connection** para adicionar um MCP server não listado
4. Clique em **Connect** e siga o fluxo de sign-in ou cole uma key
5. Escolha quais tools dessa connection este agent deve ter

As credenciais são criptografadas e nunca expostas ao seu time. Connections adicionadas dessa forma ficam armazenadas no **nível da org** — aparecem em **Settings → Connections** e podem ser anexadas a outros agents também.

<Callout type="tip">
  Você também pode começar por **Settings → Connections** e instalar uma connection antecipadamente, e depois anexá-la aos agents. O resultado é o mesmo — escolha a ordem que fizer mais sentido.
</Callout>

O catálogo é populado pelos registries habilitados em **Settings → Store**.

## Converse com ele

Basta digitar. O agent usa as tools que você anexou.

```
Send an email to me@example.com with a poem about MCP.
```

Acompanhe a execução no chat. Cada chamada de tool é registrada em **Settings → Monitor**.

<Callout type="success">
  Tudo pronto! A partir daqui, configure [Automations](/pt-br/studio/automations) para rodar agents em um schedule ou evento, convide [members](/pt-br/studio/user-management) do time, ou construa mais agents.
</Callout>
