## O control plane para seus agentes de IA

O deco Studio é o control plane open-source para seus agentes de IA — **um único endpoint MCP para todos os seus agents, tools e models**. Construa e contrate agents, conecte-os às suas tools, execute-os em schedules ou eventos e **acompanhe cada token e cada dólar em tempo real**. Use a cloud ou faça self-host na sua própria infraestrutura — construído sobre o [Model Context Protocol](https://modelcontextprotocol.io).

### Agents

Um agent é uma IA configurada para um trabalho específico: um conjunto focado de tools, instruções claras e seu próprio histórico de thread. Agents são a superfície de trabalho do Studio — você passa a maior parte do tempo dentro de um. Cada agent também é seu próprio endpoint MCP, então clients externos como Cursor e Claude Desktop podem usá-lo diretamente.

### Connections

Plugue qualquer tool ou serviço — GitHub, Slack, bancos de dados, sua própria API, qualquer coisa compatível com MCP. Configure as credenciais uma vez no nível da org, depois anexe as tools que quiser a cada agent. As credenciais nunca saem do Studio.

### Automations

Execute um agent sem supervisão em um schedule ou em resposta a um evento. Anexado a um agent específico, então o escopo do que a execução pode fazer é o que você configurou para aquele agent.

### Observability

**Saiba quanto custa cada agent.** Cada chamada de tool feita pelos seus agents é registrada automaticamente — quem chamou, quando, o que retornou, quanto tempo levou e quanto custou. Acompanhe o gasto de tokens entre providers, latência e taxas de erro em um único lugar para debugar, auditar e monitorar performance.

### Extensibilidade

O Studio é aberto em todas as camadas:

- **MCP apps** — empacote tools com views em React em um único pacote, e o Studio renderiza essas views diretamente dentro do agent. Comece pelo [template repo](https://github.com/decocms/mcp-app).
- **Sandboxes** — vincule um agent a um repositório do GitHub e o Studio o executa como um ambiente de dev isolado com escopo daquele agent (tipicamente o próprio MCP server do agent).
- **Git-native** — agents baseados em código vivem em um repo real com branches e PRs, exibidos na aba **Review changes** do agent. Seu controle de versão continua sendo sua fonte da verdade.
- **MCP em todos os lugares** — cada agent é exposto como seu próprio endpoint MCP, chamável a partir do Cursor, Claude Desktop, seu próprio código ou outro agent.

### Digital Experience: agents empacotados sobre o Studio

Para times que gerenciam storefronts e experiências digitais ricas em conteúdo, a deco oferece uma **suíte Digital Experience** construída sobre o Studio — a principal é o **[Agentic CMS](./agentic-cms)**, a evolução do [deco.cx](https://docs.deco.cx). Veja [Digital Experience](./digital-experience) para o panorama completo.

## Três formas de trabalhar

O Studio se adapta ao seu nível. O mesmo produto suporta três tipos de trabalho, e você transita entre eles livremente:

- **Chat — para todo mundo.** Basta conversar com o [Decopilot](./decopilot/overview), o pilot embutido na sua tela inicial. Peça o que quiser e ele resolve — respondendo perguntas, executando suas tools e até criando agents, automations e connections _por_ você. Um usuário totalmente novo e não técnico já consegue ser produtivo no primeiro dia, sem configurar nada.
- **Configurar — para power users.** Quando você quer sistemas repetíveis, monte-os na mão: desenhe [agents](./agents) focados, escolha a dedo suas [tools](./connections), agende [automations](./automations) e gerencie roles e acesso. Você está construindo a máquina da qual o time inteiro depende.
- **Construir — para desenvolvedores.** Vá mais fundo com código. Vincule um agent a um [sandbox](./agents#where-an-agent-runs) e a um repo Git, rode-o localmente com seu próprio harness e estenda o próprio Studio publicando [MCP apps](./agents) — tools empacotadas com sua própria UI em React. Seu repo continua sendo a fonte da verdade.

A maioria dos times usa as três ao mesmo tempo: o pilot para tarefas rápidas, sistemas feitos à mão para a rotina e código para qualquer coisa sob medida.

### O que você pode fazer com o Studio

| | |
|---|---|
| **Construir e contratar agents** | Componha workers de IA focados a partir das suas tools e instruções — ou contrate agents prontos na [Store](./store) |
| **Conectar tools** | Adicione GitHub, Slack, bancos de dados ou qualquer MCP server com OAuth em um clique — as credenciais ficam seguras |
| **Rodar hands-free** | Dispare agents em schedules ou eventos com automations |
| **Ver tudo** | Logs, custos e traces de cada ação de agent, em um único dashboard |
| **Estender com código** | Publique MCP apps (tools + UI) e vincule agents a repos Git em seus próprios sandboxes |
| **Controlar acesso** | Gerencie quem pode usar quais tools com roles e permissões de time |
| **Rodar do seu jeito** | Self-host na sua própria infraestrutura ou use nossa cloud |

### Opções de deployment

| | |
|---|---|
| **Cloud** | [studio.decocms.com](https://studio.decocms.com) — gerencie tudo pelo navegador |
| **Desktop** | `brew install --cask deco-studio` — rode agents na sua máquina com sua assinatura do Claude Code ou Codex |
| **Team** | Connections, roles e tracking de custos compartilhados em toda a organização |
| **Self-hosted** | Faça deploy na sua própria infraestrutura com Docker ou Kubernetes |
