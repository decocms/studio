description: Encontre MCPs no registry da Deco

A página de [Connections](/pt-br/studio/connections) lista os MCPs do registry da Deco. Pesquise no catálogo, escolha um MCP e conecte-o à sua organização.

O catálogo vem do [registry.json no decocms/mcps](https://github.com/decocms/mcps/blob/main/registry.json). Descrições, URLs, ícones e a lista de MCPs são alterados nesse arquivo por pull request.

O Studio mantém o arquivo em cache por cinco minutos. Se a atualização falhar, pode usar a última versão válida por até uma hora. Os itens do catálogo não ficam no banco de dados do Studio.

As conexões instaladas mantêm suas configurações e credenciais no Studio. Também é possível adicionar uma conexão personalizada pela página de Connections.
