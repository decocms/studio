## Visão geral

Lê um resource do escopo atual. Suporta herança de escopo (project herda de org, agent herda de project+org). Resources podem ser documentação, diretrizes, trechos de código ou qualquer informação contextual.

## Disponibilidade

- **Tasks**: ✓ Disponível
- **Subtasks**: ✓ Disponível

## Assinatura

```typescript
resource_read(
  resource_uri: string,
  options?: RangeOptions
)

type RangeOptions = {
  lineStart?: number
  lineEnd?: number
}
```

## Parâmetros

| Parâmetro | Tipo | Obrigatório | Descrição |
|-----------|------|----------|-------------|
| `resource_uri` | `string` | Obrigatório | URI identificador do resource |
| `options` | `RangeOptions` | Opcional | Opções de intervalo de linhas |
| `options.lineStart` | `number` | Opcional | Número da linha inicial (padrão: 0) |
| `options.lineEnd` | `number` | Opcional | Número da linha final (padrão: 20) |

## Retorno

Conteúdo e metadados do resource:
- **content**: O conteúdo de texto do resource
- **uri**: URI do resource
- **metadata**: Informações adicionais sobre o resource

## Comportamento

- Suporta herança de escopo:
  - Resources de project herdam dos resources da organization
  - Resources de agent herdam dos resources de project + organization
- Defina `options.lineStart` e `options.lineEnd` como 0 para ler o resource inteiro
- O comportamento padrão (sem options) lê as primeiras 20 linhas (linhas 0-20)
- Números de linha são indexados a partir de zero

## Exemplos de uso

### Ler o resource inteiro

```typescript
// Read entire coding guidelines document
resource_read("coding-guidelines.md", { lineStart: 0, lineEnd: 0 })
```

### Ler linhas específicas

```typescript
// Read lines 10-30 of API documentation
resource_read("api-docs.md", { lineStart: 10, lineEnd: 30 })
```

### Ler o início do resource

```typescript
// Read first 20 lines (default)
resource_read("onboarding-guide.md")
```

### Tipos de resource

```typescript
// Read coding standards
resource_read("standards/typescript-style.md", { lineStart: 0, lineEnd: 0 })

// Read deployment procedures
resource_read("procedures/deployment-checklist.md", { lineStart: 0, lineEnd: 0 })

// Read API documentation
resource_read("docs/rest-api-reference.md", { lineStart: 0, lineEnd: 0 })
```

## Casos de uso

### Execução orientada por contexto

Leia diretrizes antes de executar um trabalho:

```typescript
// Read coding standards
const standards = resource_read("coding-standards.md", { lineStart: 0, lineEnd: 0 })

// Apply standards when generating code
// ... code generation logic
```

### Referência de documentação

Acesse documentação de referência durante uma task:

```typescript
// Read API docs
const apiDocs = resource_read("api-reference.md", { lineStart: 0, lineEnd: 0 })

// Use docs to make correct API calls
// ... API call logic
```

### Conformidade com procedimentos

Siga procedimentos documentados:

```typescript
// Read deployment checklist
const checklist = resource_read("deployment-checklist.md", { lineStart: 0, lineEnd: 0 })

// Follow each step in the checklist
// ... deployment logic
```

## Herança de escopo

Resources seguem a hierarquia de escopo:

1. **Escopo de agent**: Herda de project + organization
2. **Escopo de project**: Herda da organization
3. **Escopo de organization**: Resources do nível base

Ao ler um resource, o sistema busca do escopo mais específico (agent) para o menos específico (organization).
