## Visão Geral

O Decopilot fornece ferramentas integradas que estão sempre disponíveis (sujeitas a restrições de tarefas/subtarefas). Essas ferramentas permitem gerenciamento de trabalho, acesso ao contexto e coordenação de agentes.

## Categorias de Ferramentas

### Descoberta e Habilitação

- [**enable_tool**](/pt-br/studio/api-reference/built-in-tools/enable-tool) — Ativar uma ou mais ferramentas de escopo para uso nos próximos passos

### Gerenciamento de Tarefas

- [**subtask**](/pt-br/studio/api-reference/built-in-tools/subtask-run) — Criar uma subtarefa com contexto isolado, opcionalmente vinculada a um agente específico

### Interação com o Usuário

- [**user_ask**](/pt-br/studio/api-reference/built-in-tools/user-ask) — Perguntar ao usuário quando precisar de entrada ou esclarecimento

### Acesso ao Contexto

- [**read_resource**](/pt-br/studio/api-reference/built-in-tools/resource-read) — Ler documentação ou diretrizes do escopo atual
- [**read_prompt**](/pt-br/studio/api-reference/built-in-tools/prompt-read) — Ler um template de prompt reutilizável

### Trabalhando com Saídas de Ferramentas

- **read_tool_output** — Reler um resultado grande de ferramenta que foi enviado ao armazenamento

### Pesquisa e Mídia

Registradas condicionalmente com base nos modelos padrão configurados:

- **web_search** — Pesquisa web profunda (requer modelo de web research)
- **generate_image** — Geração de imagens (requer modelo de imagem)

### Planejamento

- **propose_plan** — Propor um plano para aprovação. Só é registrada quando o modo de chat é `plan`.

### Ferramentas de Sandbox (VM)

Quando um agente está vinculado a um repositório GitHub (sandbox), o decopilot ganha seis ferramentas de VM — `bash`, `read`, `write`, `edit`, `grep`, `glob` — que operam dentro daquele sandbox.

## Matriz de Disponibilidade

| Ferramenta | Tarefa | Subtarefa | Notas |
|------|:----:|:-------:|-------|
| `enable_tool` | ✓ | ✓ | Ativa uma ferramenta de escopo para o próximo passo |
| `subtask` | ✓ | ✗ | Previne delegação infinita |
| `user_ask` | ✓ | ✗ | Subtarefas não podem interromper o usuário |
| `read_resource` | ✓ | ✓ | |
| `read_prompt` | ✓ | ✓ | |
| `read_tool_output` | ✓ | ✓ | |
| `web_search` | ✓ | ✓ | Condicional ao modelo de web research |
| `generate_image` | ✓ | ✓ | Condicional ao modelo de imagem |
| `propose_plan` | ✓ | ✗ | Apenas em plan mode |
| Ferramentas de VM (`bash`, `read`, `write`, `edit`, `grep`, `glob`) | ✓ | ✓ | Apenas quando o agente tem sandbox |

<Callout type="info">
  **Tarefas** são iniciadas pelo usuário e têm acesso completo a todas as ferramentas integradas. **Subtarefas** são criadas pelo decopilot e têm acesso restrito para evitar delegação infinita e bloqueio de interações com o usuário. Subtarefas têm um limite de 15 passos (vs 30 para tarefas) e devem retornar um resumo.
</Callout>

<Callout type="tip">
  **Descoberta de ferramentas**: As ferramentas de escopo dos servidores MCP conectados são descobertas implicitamente através das conexões listadas no MCP Virtual do escopo atual — não há uma ferramenta explícita de busca.
</Callout>
