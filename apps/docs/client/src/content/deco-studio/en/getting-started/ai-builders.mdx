## Build your first AI app

Create an app that writes poems, saves them, and emails them to your team.

<StepGroup>
  <Step number={1} title="Connect an app">
    1. Log in to [admin.decocms.com](https://admin.decocms.com)
    2. Navigate to your organization and project
    3. Click **Apps** in the sidebar
    4. Browse available integrations or open **Store** to add new ones
    5. Select the Gmail app from the store
    6. Connect it and authorize your account

    <Callout type="info">
      Apps are pre-built integrations that give your agents tools to work with. They're the building blocks for anything you want to automate.
    </Callout>
  </Step>

  <Step number={2} title="Test it in chat">
    Open **New Thread** from the sidebar and ask:

    ```
    Create a poem about deco CMS, save it to a document, and email it to you@yourcompany.com
    ```

    Watch deco chat:
    - Write the poem
    - Save it as a document
    - Send it via Gmail

    <Callout type="tip">
      Use **@ mentions** to direct a specific tool — for example, `@SEND_EMAIL` to make sure it uses Gmail.
    </Callout>
  </Step>

  <Step number={3} title="Make it reusable">
    Turn this one-off task into something anyone on your team can run.

    ### Create an agent

    Go to **Agents** → **New Agent**:
    - Give it a name and clear instructions for what it should do
    - Assign the tools it needs (document creation and email sending)
    - Save — now anyone can use it

    ### Create a workflow

    From **Workflows** → **New Workflow**, describe what you need in plain language:

    ```
    Create a workflow called "poem-mailer" that:
    1. Takes a topic and a list of recipients
    2. Generates a poem about the topic
    3. Saves it as a document
    4. Emails it to recipients every morning at 9am
    ```

    You can start simple and iterate — just describe changes the way you'd explain them to a colleague.

    ### Create a custom view

    Build an interface for your content:

    ```
    Create a view called "poem-gallery" that shows all saved poems in a
    3-column grid. Each card shows the title, a short description, and
    the creation date. Add a search bar to filter by name.
    ```
  </Step>
</StepGroup>
