## What are Virtual MCPs?

A **Virtual MCP** is a curated set of tools, context, and instructions — pulled from one or more connections — exposed as a single endpoint your agents can use.

Instead of giving an agent access to everything from every connection, you build a Virtual MCP that contains exactly what's needed for a specific use case. Virtual MCPs are the building blocks behind [Projects](/en/studio/projects) and [Agents](/en/studio/agents) — both are Virtual MCPs configured for different purposes.

## What you can do with them

**Combine tools from multiple connections**

Pick tools from several services and expose them together. An order fulfillment Virtual MCP might pull order tools from Shopify, shipping tools from ShipStation, and notification tools from your email provider — your agent uses one endpoint and gets all three.

**Add custom instructions and context**

Layer in resources (guidelines, documentation, brand rules) and prompt templates your team uses repeatedly. These travel with the Virtual MCP so any agent using it gets the right context automatically.

**Control exactly what's available**

Select only the tools that matter. Leaving out what isn't needed keeps agents focused and prevents unintended actions.

**Update without reconfiguring agents**

Change what's included in a Virtual MCP and every agent using it picks up the change automatically — no reconfiguration required.

## How tool conflicts are handled

When two connections expose a tool with the same name, the one from the connection listed first in the Virtual MCP wins. The duplicate is dropped silently.

To avoid this: curate your tool selection to include only what you need from each connection, or reorder connections to prioritize the version you want.

Tools defined directly on the Virtual MCP always take priority over tools from connections.

## Real-world examples

**Order fulfillment** — Shopify (orders) + ShipStation (shipping) + email (notifications) in one place

**Customer service hub** — Shopify order lookup and refund tools, plus custom response templates and return policy guidelines

**Multi-brand management** — Shared Shopify connection scoped per brand, so each team only sees their own products and orders

**Sales analytics** — Shopify, Google Analytics, and Stripe tools together for end-to-end conversion tracking
