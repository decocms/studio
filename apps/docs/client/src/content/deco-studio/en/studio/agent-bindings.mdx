## What are agent bindings?

Agent bindings let your custom MCP tools call a [decopilot agent](/en/studio/agents) and stream its responses. This means you can build a tool that hands off work to an AI agent and returns its answer — all within a single tool call.

A common pattern: a customer support tool that receives a question, passes it to an agent, and streams the agent's reasoning and response back to the user.

## Declaring a binding

In your `StateSchema`, use `AgentOf()` to declare which agent your tool will call:

```typescript
// api/types/env.ts
import type { DefaultEnv } from "@decocms/runtime";
import { AgentOf } from "@decocms/runtime";
import { z } from "zod";

export const StateSchema = z.object({
  MY_AGENT: AgentOf(),
});

export type Env = DefaultEnv<typeof StateSchema>;
```

When someone installs your MCP app, they'll see a picker for `MY_AGENT` where they select which agent to connect. At runtime, `MY_AGENT` becomes a client with a `STREAM` method — no HTTP or streaming parsing needed.

## Using the agent in a tool

```typescript
import { createTool } from "@decocms/runtime/tools";
import { z } from "zod";
import type { Env } from "../types/env.ts";

export const askAgentTool = (env: Env) =>
  createTool({
    id: "ask_agent",
    description: "Ask the configured agent a question and stream the response",
    inputSchema: z.object({
      question: z.string().describe("The question to ask"),
    }),
    outputSchema: z.object({
      answer: z.string(),
    }),
    execute: async ({ context }) => {
      const stream = await env.MY_AGENT.STREAM({
        messages: [{ role: "user", parts: [{ type: "text", text: context.question }] }],
      });

      let answer = "";
      for await (const message of stream) {
        for (const part of message.parts) {
          if (part.type === "text") {
            answer += part.text;
          }
        }
      }

      return { answer };
    },
  });
```

## Multi-turn conversations

Pass a `thread_id` to keep context across multiple calls:

```typescript
const threadId = crypto.randomUUID();

const stream1 = await env.MY_AGENT.STREAM({
  messages: [{ role: "user", parts: [{ type: "text", text: "What's the weather?" }] }],
  thread_id: threadId,
});

// Second turn — the agent remembers the first
const stream2 = await env.MY_AGENT.STREAM({
  messages: [{ role: "user", parts: [{ type: "text", text: "How about tomorrow?" }] }],
  thread_id: threadId,
  memory: { windowSize: 10, thread_id: threadId },
});
```

## STREAM parameters

| Parameter | Description |
|---|---|
| `messages` | Messages to send to the agent (required) |
| `thread_id` | Thread ID for multi-turn conversations |
| `memory` | Memory config for conversation continuity |
| `credentialId` | Override the credential used for model access |
| `thinking` / `coding` / `fast` | Override model per tier |
| `toolApprovalLevel` | `"auto"` \| `"readonly"` \| `"plan"` |
| `temperature` | Sampling temperature |

All overrides default to whatever was configured at install time.

### Model tiers

| Tier | Purpose |
|---|---|
| `thinking` | Primary model for reasoning and complex tasks |
| `coding` | Optimized for code generation (falls back to `thinking` if not set) |
| `fast` | Lightweight model for quick responses |

## Calling an agent from outside an MCP app

If you need to call an agent from a script or external service, use `createDecopilotClient`:

```typescript
import { createDecopilotClient } from "@decocms/runtime/decopilot";

const client = createDecopilotClient({
  baseUrl: "https://studio.decocms.com/api",
  orgSlug: "my-org",
  token: "your-api-key",
});

const stream = await client.stream({
  agent: { id: "agent-uuid" },
  messages: [{ role: "user", parts: [{ type: "text", text: "Hello" }] }],
});

for await (const message of stream) {
  console.log(message);
}
```
