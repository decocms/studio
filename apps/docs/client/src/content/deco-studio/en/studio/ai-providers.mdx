## What are AI providers?

**AI Providers** are the AI model services that power [Decopilot](/en/studio/decopilot/overview) and your agents. You connect a provider once at the organization level, and all your agents can use it from there.

Studio supports multiple providers at the same time, so you can use different models for different tasks.

## Supported providers

| Provider | How you connect |
|---|---|
| **Deco AI Gateway** | Sign in with your browser, or use an API key. Gives you access to 100+ models through one account. |
| **Anthropic** | Paste your API key from the Anthropic Console |
| **Google** | Paste your API key from Google AI Studio |
| **OpenRouter** | Sign in with your browser, or use an API key. Access to 100+ model families. |
| **Claude Code** | Detected automatically from your local CLI — no key needed |

<Callout type="info">
  The Deco AI Gateway is optionally enabled via the `DECO_AI_GATEWAY_ENABLED` environment variable. When enabled, it gives you access to models from multiple vendors through a single billing relationship.
</Callout>

## Connecting a provider

**API key** — the most common method. Paste the key from your provider's dashboard. It's stored securely and never exposed to your team.

**Sign in with browser** — for providers that support it (OpenRouter, Deco AI Gateway). You'll be taken to the provider's login page, authorize access, and Studio handles the rest.

**Claude Code CLI** — for Claude Code integration only. If you have the CLI installed and authenticated, Studio detects it automatically.

## What models are available?

Once a provider is connected, you can browse its available models. Each model shows:

- Its name and capabilities (text, vision, image generation, etc.)
- Context window size
- Pricing per token

Model availability may be filtered by your organization's model permission settings. If a model you expect isn't showing up, check with your org admin.

## Credits and billing

For the Deco AI Gateway, you can check your remaining credit balance and top up directly from Studio. Check your balance if you're seeing generation failures — running out of credits is a common cause.

## How providers are used

When Decopilot or an agent processes a task, it selects a model from your active providers based on the task at hand. If one provider is unavailable, Studio falls back to an alternative automatically.
