## The home for your AI agents.

deco Studio is where you connect tools, organize work into projects, and see exactly what your agents are doing — and what it costs. Self-host or use the cloud. Built on the [Model Context Protocol](https://modelcontextprotocol.io).

### Agents

Browse and hire AI agents from the built-in store. Each agent comes with specific skills and tested instructions. Agents can work together — one can call another. Every action is tracked with cost attribution.

### Connections

Connect any tool or service through the web UI — one-click for most SaaS apps. Monitor usage, errors, and costs per connection. Share tools across your team without sharing credentials.

### Projects

Projects bring agents and connections together around a goal. The UI adapts to what's inside — add a content agent and a CMS connection, the sidebar shows content management; add an analytics agent and a database, it shows dashboards and queries.

### Observability

See every tool call with timing, inputs, outputs, and cost. Spot what's slow, what's failing, and what's expensive — all in one place.

### What you can do with Studio

| | |
|---|---|
| **Hire agents** | Browse the store, configure, and deploy AI agents to your team in minutes |
| **Connect tools** | Add GitHub, Slack, databases, or any MCP server — credentials stay secure |
| **Organize by project** | Keep agents and tools together around specific goals or teams |
| **See everything** | Logs, costs, and traces for every agent action, in one dashboard |
| **Control access** | Manage who can use which tools, with team roles and permissions |
| **Run on your terms** | Self-host on your own infrastructure or use our cloud |

### Deployment options

| | |
|---|---|
| **Local** | `bunx decocms` — runs entirely on your machine, fully private |
| **Cloud** | [studio.decocms.com](https://studio.decocms.com) — manage everything from your browser |
| **Team** | Shared connections, roles, and cost tracking across your organization |
| **Self-hosted** | Deploy to your own infrastructure with Docker or Kubernetes |
