The [Connections](/en/studio/connections) page lists MCPs from the Deco registry. Search the catalog, choose an MCP, and connect it to your organization.

The catalog comes from [registry.json in decocms/mcps](https://github.com/decocms/mcps/blob/main/registry.json). Changes to descriptions, URLs, icons, and available MCPs are made in that file through a pull request.

Studio caches the file for five minutes. If a refresh fails, it can serve the last valid version for up to an hour. Catalog entries are not stored in Studio's database.

Installed connections keep their configuration and credentials in Studio. You can also add a custom connection on the Connections page.
