Este guia apresenta o caminho suportado mais curto para um deployment do Studio
no Kubernetes.

Código-fonte dos charts:

- [Studio](https://github.com/decocms/studio/tree/main/deploy/helm/studio)
- [Operador de sandbox](https://github.com/decocms/studio/tree/main/deploy/helm/sandbox-operator)
- [Ambiente de sandbox](https://github.com/decocms/studio/tree/main/deploy/helm/sandbox-env)

<Callout type="tip">
  Este é o guia curto mantido na rota legada da documentação. Use a
  [referência canônica de Kubernetes](/pt-br/studio/self-hosting/deploy/kubernetes)
  para requisitos de produção, permissões S3, isolamento de sandbox, gateways

</Callout>

## Modelo de deployment

Um deployment completo de agentes hospedados tem três releases:

| Chart | Escopo | Finalidade |
| --- | --- | --- |
| `chart-deco-studio` | Por ambiente do Studio | Front door nginx, containers de API, workers de fila, NATS e observabilidade opcional |
| `sandbox-operator` | Por cluster | Controller e CRDs do agent-sandbox do Kubernetes SIGs |
| `sandbox-env` | Por ambiente do Studio | Template de sandbox, RBAC, Secret sentinela e, opcionalmente, warm pool e Gateway de preview |

A topologia atual de API/worker exige PostgreSQL. Sandboxes hospedados também
exigem object storage compatível com S3.

## Instalação

Fixe as versões dos charts usadas neste checkout:

```bash
export STUDIO_CHART_VERSION=0.12.4
export SANDBOX_OPERATOR_CHART_VERSION=0.1.3
export SANDBOX_ENV_CHART_VERSION=0.9.13
```

### 1. Instale o operador de sandbox

```bash
helm install sandbox-operator \
  oci://ghcr.io/decocms/studio/charts/sandbox-operator \
  --version "$SANDBOX_OPERATOR_CHART_VERSION" \
  --namespace agent-sandbox-system \
  --create-namespace
```

### 2. Configure e instale o Studio

Crie um Secret estável do Kubernetes no namespace `deco-studio` contendo
`DATABASE_URL`, `BETTER_AUTH_SECRET`, `ENCRYPTION_KEY`, `S3_ENDPOINT`,
`S3_BUCKET`, `S3_ACCESS_KEY_ID` e `S3_SECRET_ACCESS_KEY`.

Crie `studio-values.yaml`:

```yaml
database:
  engine: postgresql
  url: "" # fornecido como DATABASE_URL pelo Secret existente

serviceAccount:
  create: true
  name: deco-studio
  automount: true

configMap:
  meshConfig:
    BETTER_AUTH_URL: "https://studio.example.com"
    BASE_URL: "https://studio.example.com"
    STUDIO_SANDBOX_PROVIDER: "agent-sandbox"
    STUDIO_ENV: "production"
    STUDIO_SANDBOX_TEMPLATE_NAME: "studio-sandbox-production"

secret:
  secretName: deco-studio-secrets
```

<Callout type="note">
  `configMap.meshConfig` é um nome de chave obsoleto do chart, mantido para
  compatibilidade de upgrade. Seus valores configuram a API do Studio. Não
  coloque credenciais ali; mantenha-as no Secret.
</Callout>

Instale o chart da aplicação:

```bash
helm install deco-studio \
  oci://ghcr.io/decocms/chart-deco-studio \
  --version "$STUDIO_CHART_VERSION" \
  --namespace deco-studio \
  --create-namespace \
  --values studio-values.yaml
```

O Deployment principal contém nginx e dois containers de API. Um Deployment
separado de workers é obrigatório e vem habilitado por padrão.

### 3. Instale os recursos de sandbox do ambiente

```bash
helm install sandbox-env-production \
  oci://ghcr.io/decocms/studio/charts/sandbox-env \
  --version "$SANDBOX_ENV_CHART_VERSION" \
  --namespace agent-sandbox-system \
  --set envName=production \
  --set mesh.namespace=deco-studio \
  --set mesh.serviceAccountName=deco-studio
```

<Callout type="note">
  A chave `mesh.*` do chart de sandbox também tem nome obsoleto e é mantida
  para compatibilidade; ela aponta para a release do Studio.
  `mesh.serviceName`, `mesh.servicePort` e `mesh.podSelectorLabels` estão
  obsoletos e não são usados.
</Callout>

## Verificação

```bash
helm status deco-studio -n deco-studio
helm status sandbox-operator -n agent-sandbox-system
helm status sandbox-env-production -n agent-sandbox-system

kubectl get deployments,pods -n deco-studio
kubectl get sandboxtemplate,sandboxwarmpool -n agent-sandbox-system
kubectl port-forward svc/deco-studio 8080:80 -n deco-studio
```

O Studio estará disponível em `http://localhost:8080`.
