### 7a port ledger (main since #6187's base `4af860cbf`)

In priority order. "Go" = `controller-go` on the #6187 ref.

1. **#7471** (114ccc044): replace Go's fixed 180s ready timeout with
   progress-based waiting (fail on `failed` phase; else only after 10 min
   without a phase change). In `ensureLocked`, a claim with no row: wait out
   a `deletionTimestamp`; join a not-ready one (cold: token/boot id from
   `claim.spec.env`; warm: sentinel) and delete only if the join fails;
   adopt a ready one. Go today waits 60s for a live starting claim to vanish.
2. **Tenant pools** (9ea3da239, 803344b40, 55df99464): harness runs may bind
   pools; tenant-pool claims use `-medium`; drop `cloneOnly` when a pool pod
   was bound; github.com-only repo key; return `warmPoolAdopted`. **Go sets
   `warmpool: "default"`; TS names the pool (`claimWarmPoolName`). Check
   whether "default" can hand a claim another org's tenant pod.**
3. **Images** (a26e68a1d): `EnsureOptions.sandboxImage` (Go's `image` is
   dead), `<base>[-<image>][-medium]`, per-name 60s TTL probe cache,
   fallback drops the image suffix, non-default image skips tenant pools,
   keep `sandboxImage` in persisted opts.
4. **Credentials / repos**: `repositoryId` on `Repo` and the clone-url
   callback (803344b40, callback re-mints via `cloneInfoForRepository`);
   `extraRepos` + `directoryName` → `git.repositories` always sent, empty
   included (1711c425e); org-fs re-mint callback, relay on resume/adopt
   (6ffda01b4, 2bd690313).
5. **Small**: `evictionMessage` in `PodTermination` (81da03a6a); daemon-call
   retries with per-attempt timeout, body drain, malformed-2xx label
   (6071564bb, c6d3dcb31, 4d14b083d, 17b500379, 2fa4e7523), and never retry
   a `rotateToken` POST after a timeout; typed `bootstrap-rejected` error
   (2d1df145f); drop `OffloadAllowedHosts`/`OffloadAllowSameHost`
   (1056e34fb, 3c49f1e9d).
6. **Studio side**: the `SandboxProvider` interface and provider registry
   are gone (6b1b4066a, 20b4cf11c); `RemoteSandboxProvider` must match
   `AgentSandboxProvider`'s public surface, incl. `renewTtl` →
   `PATCH lifetime` (4dd9096ac). TS type is now `EnsureRepo`.

Traps found while porting 1a once (then parked):

- `pkg/protocol` = main's `internal/config/types.go` wire types + methods,
  aliased back into `config`; health route returns `protocol.Health`
  embedded with `orchestrator`. Daemon e2e was 96/96 with that change.
- `SubmoduleCredentials` / `Repositories` are `omitempty`: Go drops an empty
  slice, the daemon reads absent as "keep current", so a revoked PAT or
  dropped repo survives on a reused pod when Go builds the payload. Drop
  `omitempty` (or use a slice pointer) for payloads the controller builds.
- TS `stripEnsureOpts` does not persist `extraRepos` (resurrect loses
  secondary checkouts); don't copy that into Go.

## Spec deltas found while building

- `SandboxVariant` name is `<baseTemplate>-<v>` with `spec.baseTemplate`:
  stg and prod templates share `agent-sandbox-system` (chart hardcodes it).
  The control-plane spec's "stg and prod differ by namespace" is wrong for
  templates; its table key should be `(cluster, baseTemplate, variant)`.
- `Ready` stays True while a previous render serves (Rendered=False).
  Variant names may not be `medium` or end in `-medium`.
- Argo CD syncs the chart: chart N needs
  `argocd.argoproj.io/sync-options: Prune=false` as well as Helm's `keep`.
- Operator 0.4.5 serves `v1alpha1` only (open question 3 answered).
