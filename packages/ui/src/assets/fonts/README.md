# Fonts

The product speaks in one face, Geist, with Geist Mono for code and
identifiers. The deco theme calls the family "Sidebar Geist"; it is Geist.

**License**: SIL Open Font License (OFL) 1.1 — `OFL.txt` must ship alongside
the font files.
**Source**: the `geist` npm package (Vercel, with basement.studio).

## Geist — every role

Interface, headings, display and prose. Variable, 100–900.

- `Geist-Variable.woff2`, `Geist-Italic-Variable.woff2`

## Geist Mono — code and identifiers

Strings you copy or compare character by character: run ids, SHAs, file paths,
commands, code blocks. Not captions; a status or a relative time is language.

- `GeistMono-Variable.woff2`
